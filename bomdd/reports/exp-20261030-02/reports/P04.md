# UI モック受入検査報告書 — ViewTube V1 UI-CAD(ECO-VT-035 provisional)

## 0. 検査の前提

- 入力: 本フォルダの `notes/design-intent.md`、`notes/unresolved-questions.md`、`mock/viewtube-v1.html`(DOM・CSS・capture 用 script)、`ruled/10-requirements.yaml`、`ruled/20-spec.md` だけ。
- mock はブラウザで描画せず、HTML/CSS/script を文字として読んだ。capture 状態は script の `capture.get(...)` 分岐を追って再構成した。
- パッケージの外を指す参照(`../fixtures/ECO-VT-031/*.bmp`、`bomdd/ui/ui-ir.json`、`bomdd/35-design-system-bom.yaml`、`bomdd/db/schema-intent.md` 等)は**本パッケージからは検証不能**として扱い、中身を推測していない。
- 仕様末尾の Phase 5 addendum(ECO-VT-001〜005)は契約文として引用するが、実装の現状の推定には使っていない。
- パッケージ自身の状態表示: meta `viewtube-ui-cad-status` = `ECO-VT-035 provisional-1-pending-golden`、UQ-UI-007 は open(pending CAD/mock golden)。以下は判定でなく**候補と質問**である。
- 証拠の種類: 「可視」= 描画される DOM、「潜在」= `display:none` / `.hidden` の DOM、未使用の CSS class、script だけにある状態。各項目にどちらかを記した。

## 層2: カバレッジ写像

### 2.1 画面と状態

capture のパラメータ(script の `capture.get`)で再現できる状態:

| パラメータ | 値 | 写る状態 |
|---|---|---|
| `screen` | videos / tags | 主画面の 2 つ |

| `nodegraph` | warning / all / unclassified | Tags の分類警告(view が 制作ステータス に替わる)/ Videos の すべて・未分類 |
| `hierarchy` | clean | 既定は dirty(savebar・バッジ・点が見える)。clean で隠す |
| `modal` | channel / settings | channel 追加 modal(preview 確認済み)/ 設定 modal |
| `assignment` | closed / open / mixed | タグ付与 modal(open = あとで見る「すべて」、mixed = 出演者「一部」) |
| `thumbnail` | loaded / 既定 fallback | 取得画像(パッケージ外の fixture を参照・検証不能)/ 決定的な placeholder |
| `chrome` | 0 | CAD の状態切替を隠し、高さを 800px にする |

- **写っている画面**: Shell(topbar: ブランド・動画/タグ・設定)、Videos 3 pane(collection 一覧/結果 grid/detail)、Tags 3 pane(ビュー管理/階層構造/タグパレット)、modal 3 つ(タグ付与・channel 追加・設定)。
- **注記・仕様が言うのに写っていないもの**: list 表示、手動リンク登録 modal、tag 定義 dialog、view 設定 dialog、row menu、配置中/移動中、保存の成功/失敗、note の dirty/保存失敗、タグ付与の失敗、channel 解決の 0 件/複数件/エラー、collection 行の partial/cancelled/failed/never-synced、unavailable/未取得の動画、archive 管理面、終了確認、backup/restore、狭い幅(<1050px、右 pane を隠す CSS だけ)。

### 2.2 利用者の操作

- **Shell**: 動画/タグ の切替、設定を開く。
- **collection**: すべての動画・手動・channel を選ぶ。「＋ リンク」(先の画面なし)、「＋ チャンネル」→ 参照を入れる → preview → 「追加して同期」/「戻る」。
- **Videos の操作列**: view を選ぶ、すべて/未分類、検索、並び替え(項目と向きが一体)、grid/list、子 chip で下の階層へ(handler なし)。
- **結果**: card 本体で detail を 1 本選ぶ(Enter/Space も可)。card の checkbox で一括対象を 0〜N 本切り替える(件数表示・0 件で無効)。「タグを付ける」→ modal。
- **タグ付与 modal**: 既存タグを検索する、タグを選ぶ(すべて/なし/一部 の表示と、型ごとの値入力)、「N本に付ける」「N本から外す」、キャンセル/×。
- **detail**: 「動画を開く」、「⋯」(アーカイブ)、ローカルメモを書く・保存・破棄。
- **Tags**: ビューの新規・検索・選択。ビュー設定。階層の行のドラッグ、開閉、「結果」(Videos へ)、•••。保存/破棄(savebar)。分類警告の「設定を確認」。パレットの「＋ タグ」・検索・タグカード(配置の開始は宣言だけ)・•••(編集)。
- **設定**: 表示言語、API キーの置換/設定・削除、完了。

### 2.3 データの流れ

- **入力**: YouTube リンク(登録 modal は無い)、channel 参照(URL・@handle・ID)→ 外部で解決 → 確認して作成 → 背景で同期。タグの割当(simple は値なし、textual/numeric は値)、ローカルメモ、階層の配置、API キー(端末の資格情報)、表示言語。
- **出力・投影**: collection ごとの件数と同期状態。view の経路による結果(breadcrumb・子 chip の件数・結果の件数)。card(サムネイル/placeholder・長さ・永続 tag chip・一括の checkbox)。detail(remote の項目・取得元・tag・メモ)。タグの使用数。分類警告。状態カード。ブラウザで動画を開く(外部)。

**5 分の要約**: YouTube 動画を ID で管理するローカルカタログ。動画は手動リンクか公開 channel の同期で取り込む。分類は「タグ」と、タグを並べた「ビュー」の階層で行う。Videos ではビューの階層をパンくずと子 chip でたどり、「すべて/未分類」を切り替えて結果を見る。動画を 1 本選ぶと右に詳細とメモが出て、checkbox で選んだ複数本へ既存タグをまとめて付け外しできる。Tags では、ビューの階層をパレットのタグから組み立てて保存/破棄する。再生は外部ブラウザで行う。

## 層4: 復唱文

以下は、このモックをそのまま作った場合の製品の振る舞いである。設計者が各文に Yes/No を付けられる形で書いた。

1. 画面は「動画」と「タグ」の 2 つで、設定は右上の歯車から開く modal である。
2. 動画画面の左は collection の一覧で、「すべての動画」・手動・チャンネルに分かれる。チャンネルの行は点と文言で「同期済み」「同期中」を示す。
3. 動画画面の grid card は 160px の高さでサムネイル(取得できなければ決まった placeholder)・長さ/LIVE・永続タグの chip・一括の checkbox だけを示し、題名・チャンネル・動画 ID は card に出ない。題名は右の詳細だけに出る。
4. card 本体を押すと右の詳細が 1 本に替わり、card の checkbox は一括対象だけを切り替える。2 つの選択は別々に見える(青い枠と ✓)。
5. 一括対象が 0 本のとき「タグを付ける」は押せない。ただし見た目は変わらない。
6. 「タグを付ける」は既存タグの一覧を出す modal を開き、各タグに選択集合での「すべて/なし/一部」を文言で出す。新しいタグはここでは作れない。
7. simple タグは値を入れずに付け外しし、textual・numeric タグは用意された選択肢から値を 1 つ選んで全員に揃える。数値を自由に入れる欄はない。
8. 付与/解除が失敗すると modal と選択が残る、と予告文で示す。失敗した後の画面は本モックからは未規定。
9. ビューを選ぶと、パンくず(ビュー名 › 階層の node)と子 chip(件数つき)が出て、「すべて/未分類」で結果・chip の件数・見出しの件数がまとめて切り替わる。
10. 階層を上に戻る操作(パンくずを押す等)と、子 chip を押した後の振る舞いは本モックからは未規定。
11. 並び替えは「追加日↓・題名↑・チャンネル↑・公開日↓・長さ↑」の 5 択で、項目ごとに向きは 1 つに決まっている。
12. 同期中・一部完了・失敗・取消・API キーなし・読込中・空・未分類なしの各状態は、中央の結果の代わりに説明とボタン 1 つのカードを出す。カードの間は取得済みの動画も一覧に出ない。
13. 詳細は 動画ID・チャンネル・公開日・長さ・取得元・確認日時・タグ・ローカルメモ を示し、「動画を開く」で外部ブラウザを開く。canonical URL・公開状態・説明文の表示は本モックからは未規定。
14. メモは保存/破棄のボタンで確定するが、未保存の印と保存失敗の表示は本モックからは未規定。
15. 詳細の「⋯」でアーカイブする。アーカイブした動画を戻す場所は本モックからは未規定。
16. タグ画面は、左がビュー管理、中央が階層の編集、右がタグパレットで、各 pane が別々に scroll する。編集中は「未保存の変更」と、浮かんだ保存/破棄のバーが出る。
17. 階層の親の行にだけ開閉のボタンが出て、各行の「結果」で動画画面へ移る。移った先の経路が押した行のものになるかは本モックからは未規定(mock では常に「出演者」)。
18. 分類の設定に問題があるときだけ、中央の上に「分類設定を確認してください」と理由・「保存済みの階層は変更されていません」・「設定を確認」を出し、問題がなければ何も出さない。
19. チャンネル追加は、参照を入れると題名・ID・公開動画数の確認が出て、「追加して同期」で作る。解決のボタン・見つからない場合・複数ある場合の画面は本モックからは未規定。
20. 手動リンクの登録・手動 collection の作成・collection の削除・タグとビューの作成/編集の dialog・バックアップ/復元・終了確認は、本モックからは未規定(ボタンだけ、またはボタンもない)。
