## 層1: 内部矛盾検査

確度の表記: **確実** = 記述と DOM/値が直接食い違う / **要確認** = 解釈によっては整合しうる。

### 1-A. 操作可能とされているが、操作可能の痕跡が欠ける/非対称

**C-01 タグパレットのカードに操作の痕跡がない(確実)**
- 注記側: Tags 中央ヘッダーの hint は「パレットで選択/ドラッグで配置・並べ替え」。palette card には `data-ui-action="StartTagPlacement"` がある。
- DOM 側: 既定図の `.palette-card` は `<div>` で、role・tabindex・`cursor` がない(`.palette-card` の CSS に cursor 指定なし)。fixture 図は `role="button"` を付けたが tabindex はない。キーボードからは到達できない。

**C-02 詳細サムネイルに操作の痕跡がない(確実)**
- 注記側: ECO-VT-167 のコメントは、詳細サムネイルが OpenPreview(プレイヤーを開く)を実行し、card の 2 回目の起動も「the same operation the detail thumbnail performs」としている。
- DOM 側: 既定図の `.detail-thumb` は `<div>` で、role・tabindex・cursor・`data-ui-action` がない。fixture 図は `role="button" data-ui-action="OpenPreview"` と「プレイヤーを開く」ラベルを持つが、tabindex がない。

**C-03 右クリックメニューにしか入口がない操作(要確認)**
- 次の操作の入口は `context-menu`(状態クラス `.menu-open` で右クリックを代用)だけで、キーボードからの起動手段(メニューボタン等)が描かれていない。
  - コレクション行: アーカイブを表示/全件を再確認/新着の取り込みから外す/コレクションを削除
  - 詳細サムネイル: 別のサイズで取り直す
- REQ-068(キーボード到達性)は videos-cad.md の横断制約である。

**C-04 ノード設定ダイアログの「反映」がキャンセルと同じ動作に結ばれている(確実)**
- 既定図の `#node-dialog-save`(反映)の `data-ui-action` は `CloseNodeDialog` で、キャンセルと同一。
- 同じダイアログの展開ボタン群・別名・HOME・「この配置を削除」は `data-ui-action` を持たない。
- fixture 図は `SaveHierarchyNode` / `SetNodeExpansion` / `RemoveHierarchyNode` を持つ。部品インベントリが 2 図で非対称である。

**C-05 アーカイブ操作の見た目がラベルと食い違う(要確認)**
- 既定図の詳細のアーカイブボタンは `aria-label="アーカイブ"` だが、表示 glyph は `⋯`(「その他メニュー」と読める形)。
- fixture 図はアーカイブ箱のアイコンを使う。

### 1-D. 注記の規則と DOM/スタイルの食い違い

**C-29 card に題名とチャンネルが見えない(確実・注記同士も対立)**
- videos-cad.md VCAD-CARD-0001/0002/0003 は「card は題名(なければ動画 ID)を見える要素として持つ」「チャンネル名は既知なら表示」とする。
- 既定図の `.card-body`(題名・チャンネル・tagline)は `display:none`。fixture 図の card にも題名要素がない。
- design-intent 22 は「題名・メタデータ・メモは選択中の右detail paneで示す」とする。DOM はこちらに従っている。

**C-30 詳細ペインに必須項目が欠けている(確実)**

**C-31 range anchor の輪郭が非権威マーカーなしで描かれている(確実)**
- videos-cad.md の amendment record 2 は、anchor 輪郭を権威ではないと裁定し、「No capture … may re-display the outline without a non-authority marker」とする。

  - card・詳細へのタグの投影、件数(子 chip・結果・使用数)、パンくず。
  - ブラウザで canonical 動画を開く、プレイヤー/再生キュー。

  - セッション限りのもの: レールの折りたたみ状態、サムネイル画像バイト。

**5 分要約**: ViewTube は YouTube 動画の参照(リンク)をローカルで管理するアプリである。チャンネル単位・手動単位でコレクションに集め、型付きタグ(値なし/テキスト/数値)で分類する。保存したビュー(タグ階層)で一覧を絞り込み、一括タグ付け・メモ・アーカイブ・ブラウザで開く操作を提供する。ミュージックという予約スコープで連続再生もできる。分類の定義はビューパックとして作者のタグ付与ごと共有でき、取込は読取専用プレビュー→競合解決→原子的適用の順で行う。

## 層4: 復唱文

各文に Yes/No で答えられる形で書く。

1. 画面は「動画」と「タグ」の 2 つで、上部バーから切り替える。設定は歯車からの modal で開く。
2. 動画画面は 左=コレクション、中央=動画一覧、右=選択中の動画の詳細 の 3 ペインで、1280×800 では一覧が 2 列になる。幅が広がると列が増え、1050px 以下では右ペインが消える。
3. 動画 card には題名もチャンネル名も表示しない。見えるのは、サムネイル、長さ/LIVE、永続タグの chip、一括選択の checkbox、quick action だけである(C-29: videos-cad.md の VCAD-CARD-0001 と食い違う)。
4. card を 1 回押すと右の詳細にその動画が出る。もう一度押すとプレイヤーが開く。プレイヤーの見た目は本モックからは未規定。
5. card の checkbox は詳細の選択と独立して一括選択を切り替え、Shift で範囲選択する。範囲の起点(anchor)をどう表示するかは本モックからは未規定である(輪郭は描かれているが、権威ではないと裁定されている)。
6. 「結果を全選択」は、画面に描画した card ではなく現在の結果全体を対象にする。いまのモックでは見出しの 102 本に対し 128 件を全選択する(C-06)。
7. 選択が 0 件でも「タグを付ける」は表示され、押せない状態になる。
8. 「タグを付ける」は既存タグを選ぶ modal を開き、各タグが選択動画の「すべて/一部/なし」のどれに付いているかを文言で示す。値はタグの型に応じて、選択肢か入力欄で受ける。
9. 一括付与に失敗すると modal と選択を保持する。成功した後に選択と modal がどうなるかは本モックからは未規定。
10. 保存したビューを選ぶと、保存済み階層の任意のノードを直接選べ、すべて/未分類 の切替・パンくず・子 chip が出る。ビューを×で解除すると、それらは消えて「すべての動画」の通常一覧に戻る。
11. 詳細ペインに出るのは、ID・チャンネル・公開日・追加日・長さ・サムネイルサイズ・取得元・タグ・ローカルメモである。canonical URL・availability・最終確認時刻は出ない(C-30)。
12. メモは「保存」を押したときだけ保存され、「破棄」で元に戻る。保存せずに他の動画を選んだときの扱いは本モックからは未規定。
13. コレクション行の右クリックメニューから、アーカイブ一覧の表示・全件の再確認・新着取り込みの対象切替・削除ができる。アーカイブ一覧の画面と元に戻す操作は本モックからは未規定。
14. ローカル分類を持つコレクションは通常の削除が止まり、件数を示した別の破壊的操作だけが提示される。そのコレクションにしか属さない動画とメモも一緒に削除される。
15. タグ画面では、ビューごとにタグの階層を組み立て、明示的に保存または破棄する。未保存の階層があるまま画面を離れたときの扱いは本モックからは未規定。
16. card の quick action(1 クリックのタグ切替)はタグ定義から昇格したタグだけに出るが、昇格・順番・上限を設定する画面は本モックからは未規定。どのタグが昇格しているか(お気に入り/あとで見る/要確認)は、図によって名前が食い違う(C-13/C-14)。
17. 評価タグの値域は、タグ一覧と編集では 0〜256、付与画面では 1〜5 になっている(C-15)。
18. ビューパックは設定から書き出し・取り込みでき、書出に含めるのはチャンネル ID・タグ/ビュー定義・作成者の付与先動画 ID だけである。取込は読取専用の概要→競合の解決→1 トランザクションでの適用の順に進む。
19. 「ミュージック」は件数を持たない予約の行で、起点のビューなしでは開けない。開くと再生バーで表示順またはランダム順に連続再生でき、ミュートできる。音量調節はない。
20. API キーの状態は設定に「保存済み/未設定」と表示し、置換・削除ができる。キーを入力する画面そのものは本モックからは未規定。
