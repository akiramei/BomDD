### 1.2 整合を確認した主要点

- grid カードは `grid-auto-rows:160px`・`.video-card{height:160px}`、時間/LIVE はカード内の `.duration`、題名・メタ・メモは詳細ペイン(card-body は `display:none`)— 注記 18 行目と一致する。
- 詳細選択(`.detail-selected` = 青枠)と一括選択(batch-toggle の `aria-pressed` + ✓)は、class も見た目も別の表現。カードのクリックは `stopPropagation` で batch-toggle と分けてある — 注記 22 行目と一致する。
- 「タグを付ける」は付与 modal(`OpenTagAssignment`)を開き、タグ定義の作成(`CreateTag`)とは別のもの — 注記 23 行目と一致する。
- modal のタグ行の すべて/なし/一部 は文言(+色)で示され、カードの chip と数が合う(あとで見る 3/3、出演者 2/3、評価 1/3、職種 0/3)。
- シンプルを選んだとき値入力は隠れ(`#assignment-value.hidden`)、テキストのときだけ定義値の select が出る — 注記 24 行目と一致する(数値は C3)。
- 子件数 42+31+18=91、91+未分類 37=128=すべての動画。職種 の使用 31 = クリエイター 42 − 未分類 11 とも合う。
- 表示文言に NodeGraph は出てこない(id のみ)。ready 状態では診断パネルが `hidden` — 注記 14 行目と一致する。
- 葉の行には展開ボタンがなく、`aria-hidden` の透明な placeholder だけ(角丸面なし)— 注記 17 行目と一致する。
- 操作 control の境界 #8A95A6、muted/placeholder #536074 は CSS トークンと一致する。
- サムネイルの loaded/fallback は同じ DOM・同じ ID で `thumbnail-loaded` class だけが切り替わる。詳細も同じ規則 — 注記 19・21 行目と一致する。
- 各 pane は `pane-head`/`pane-foot`(固定)+ `pane-scroll`(スクロールは 1 つ)の構成 — 注記 10 行目と一致する。

### 2.2 ユーザー操作

- **ナビ**: 動画/タグ の切替、設定を開く。
- **コレクション**: すべての動画/手動/チャンネルの選択、＋リンク、＋チャンネル(URL・@handle・ID を入れてプレビュー → 「追加して同期」)。
- **結果の閲覧**: ビューの選択、すべて/未分類、検索(題名・チャンネル・ID・メモ)、並び替え 5 種、grid/リスト、子ノード chip で掘り下げ、パンくず。
- **選択**: カードの本体で詳細の対象を 1 件選ぶ(クリック/Enter/Space)。カードの ✓ で一括の対象を 0..N 件トグル。
- **一括タグ付与**: 「タグを付ける」→ 既存タグを検索・選択 → 型に応じた値 → 「N本に付ける」/「N本から外す」/キャンセル/×。
- **詳細**: 動画を開く、アーカイブ、ローカルメモの編集・保存・破棄。
- **タグ画面**: ビューの検索・新規・選択・設定、階層行のドラッグ並べ替え・展開/折りたたみ・「結果」(動画画面へ移る)・メニュー、パレットのタグ検索・＋タグ・定義編集・配置開始、階層の保存/破棄、警告の「設定を確認」。
- **設定**: 表示言語、APIキーの置換/設定/削除、完了。
- **状態からの回復**: 再試行・キャンセル・リンクを追加・すべてを表示・同期を再開・設定を開く。

### 2.3 データの流れ

- **入力**: チャンネル参照、動画リンク(未描画)、YouTube Data API キー、検索語、ローカルメモ、タグの値(テキストは定義値から選ぶ、数値は 0–256)、階層の構成、ビューの定義。
- **外部**: 公開チャンネルの確認と公開動画の同期(APIキーが必要)、サムネイル画像の取得(許可された場合。画像はセッション中だけ保持)。
- **出力/投影**: コレクションごとの件数、ビュー階層の評価結果(パンくず・子件数・すべて/未分類の件数)、動画カード(サムネイル・時間・永続タグ chip)、詳細(メタ・タグ・メモ)、タグの使用数、分類設定の警告。
- **書き込み**: タグの付与と解除は選択集合へ原子的に行い、成功後にカード・詳細・使用数・ビュー結果を再投影する。階層は保存/破棄、メモは保存/破棄。APIキーは画面・カタログ・バックアップ・ログに完全な値を出さない。

**要約(5 分版)**: YouTube の公開チャンネルや手動リンクを「取得元コレクション」として集めたローカルの動画カタログ。利用者は型つきのタグ(シンプル/テキスト/数値)を定義し、それを階層に並べた「ビュー」で動画を分類して見る(すべて/未分類・子件数・パンくず)。動画は 1 件を詳細で見て、複数件を ✓ で選んで既存タグを一括で付け外しできる。動画の再生画面は描かれておらず、「動画を開く」があるだけ。

## 層3: 隣接未カバー質問(手戻りコスト降順)

1. **[high] 一括選択の同一性と寿命**
   - 対象: batch-toggle・`#selected-count`・modal 見出しの ID 列。
   - 質問: 結果の集合が変わったとき(すべて⇔未分類、コレクション切替、検索、子ノードへの移動、並び替え)、一括選択はどうなるか。選択肢: (a) 動画 ID で保持し、見えていない分も含む/(b) 見えている分だけに絞る/(c) クリアする。全選択・全解除の操作は要るか。
   - 隣接の根拠: mock は選択をカードの位置で持っており、モードを切り替えると 092〜094 が選択済みになる。一方で modal は 001〜003 を出す(C18)。
   - 手戻り: 選択状態を何に結び付けるか(ID か表示か)は状態設計の根幹になる。

2. **[high] 詳細選択のライフサイクル**
