## 0. 検査の前提(読み方の宣言)

1. **1 ファイルに 2 枚の図面が入っている。** パラメータなしで描かれる「既定の図面」(L1203〜1939 の静的 markup と L1941〜3018 の script)と、`?base=fixture` のときだけ script が markup を作り直す「fixture 図面」(L3024〜3730)。本報告は**既定の図面を主たる仕様**として読み、両者の食い違いはすべて層 1 の DOM 内部矛盾として挙げる。どちらが正しいかは決めない。
2. HTML コメントはモック自身が書いた言葉なので、根拠として引用する。ただし、コメントが製品側のファイル名(MainWindow.cs など)に触れていても、そこから実装を推測することはしない。
3. 注記どうしの矛盾(design-intent と videos-cad の間)も層 1 に入れ、DOM がどちら側に付いているかを書く。
4. script が読込時に静的 markup を作り直す箇所(L2740 `renderSavedNode()`)は、**作り直した後の状態**を既定の表示とみなす。静的 markup だけに残る食い違いは「script なしのフォールバック」として low 扱いにする。

### 1-B. 整合を確認した主要点(矛盾ではないことの記録)

- 詳細選択のリング: `.video-card.detail-selected` は `var(--blue)` = `#3467e8` の枠と 2px の halo(L401、L21)。VCAD-VIS-0001/0002 と一致。
- 一括選択はカード上の独立したトグルで、本体クリックは `stopPropagation` で分けている(L2019-2020)。VCAD-CARD-0008・design-intent L30 と一致(役割は `aria-pressed` のボタンでありチェックボックスではない点は Q12)。
- 結果 grid: `repeat(auto-fill,minmax(270px,1fr))`、gap 14px、行の高さ 160px(L317)。VCAD-CARD-0015/0016・design-intent L22/L23 と一致。
- ツールバーの折り返しは window 幅ではなく container query(`container-type:inline-size`、`@container videos-toolbar (max-width:660px)` L226、L769-776)。design-intent L24・VCAD-TOOLBAR-0004 と一致。
- 右 detail の scrollbar: 通常時は thumb が透明、`:hover` と `data-scrollbar-state="active"` のときだけ表示(L334-344)。design-intent L13・UQ-UI-021・VCAD-DETAIL-0009 と一致。grid は常に表示(L328)、左欄は自動で隠れる(L383-395)。
- 0 件選択: `タグを付ける` は隠さず disabled(L1988)。master は none/mixed/all を `aria-checked` false/mixed/true と文言(`結果を全選択`/`全選択を解除`)で示す(L1986-1996)。design-intent L33・L35、VCAD-BATCH-0003/0004 と一致(母数は C5)。
- Shift 範囲: 起点から対象までを両端含みで対象の状態に揃え、範囲外はそのまま(L2022-2032)。design-intent L36 と一致。
- 保存済み階層 selector: `role="tree"`・`treeitem`・`aria-level`・`aria-selected`・`aria-expanded`(L1357-1363)。design-intent L42 と一致。
- パンくず: 祖先は stable key を持つ `button`、現在地は `strong` に `aria-current="location"`、区切りは `aria-hidden`(L2353-2376)。値経路の末尾は現在地、その親は祖先の操作になる(L2350-2352)。design-intent L43-45・VCAD-CRUMB-0002〜0004 と一致。
- ビュー未選択時: 保存済み階層・モード・パンくず・子 chip は `data-classification-only` で隠れる(L236、L1353、L1378)。VCAD-BROWSE-0001 と一致。
- 結果状態: CAD 切替に loading/syncing/partial/empty/unclassified-empty/cancelled/failed/credential の 8 状態があり、それぞれ説明文と次の操作を持つ(L2517-2526)。失敗を「動画がありません」で表していない。VCAD-STATES-0001〜0003 と一致。

### 2-2. ユーザー操作

- コレクション: 選ぶ、全チャンネルの新着を取り込む、行メニュー(アーカイブを表示・全件を再確認・新着の取り込みから外す/含める・削除)、チャンネルを追加(URL/@handle/ID → 確認 → 追加して同期)、リンクを追加(入口のみ)。
- ミュージック予約スコープ: 選ぶ、起点のビューを決める/選び直す、設定で一覧から隠す。
- 動画の閲覧: ビューを選ぶ/解除する、保存済み階層の root・中間・葉を直接選ぶ、すべて/未分類の切替、子 chip で下る、パンくずで祖先へ戻る、検索、並び替え、グリッド/リスト。
- 選択: カード本体で detail の対象を選ぶ(Enter/Space も)、一括トグル、Shift で範囲、結果を全選択/全解除。
- タグ付け: 一括付与 modal(既存タグを選ぶ → 種別ごとの値入力 → N本に付ける/外す)、quick action(お気に入り・あとで見る・要確認)をカードと detail で切り替える。
- detail: 動画を開く、アーカイブ、サムネイルを別サイズで取り直す、メモを編集して保存/破棄。
- Tags: ビューの作成・選択・検索・設定、起点の決定・選び直し・ビューなしに戻す、パレットからタグを選んで階層に配置(前に挿入・子にする・ルート末尾)、ドラッグで並べ替え、ノード設定(展開・別名・条件・HOME・配置の削除)、階層の保存/破棄、タグの作成・編集・削除、診断の警告から設定を確認。
- 設定: 表示言語、API キーの置き換え/削除、バックアップ/復元、使われていない動画の整理、ビューパックの取り込み/書き出し、ミュージックの表示切替。
- ビューパック: 書き出す内容を選ぶ → 保存。取り込み: 概要 → 取り込み先と作成者ラベル → 競合を 1 件ずつ解決 → 適用 → 結果 → コレクションを開く。各種の安全停止から「別のファイル」「プレビュー更新」「設定を開く」「同期して再計画」。
- (fixture 図面のみ)ハッシュタグをタグにする、コレクション欄を畳む、音楽の再生(すべて/選択を再生・シャッフル・ループ・前/次/一時停止/終了・シーク・ミュート・キュー表示)。

### 2-3. データの流れ

- 入力: YouTube チャンネルの参照(URL/@handle/ID)と動画リンク、YouTube Data API キー(設定でのみ)、タグ定義(シンプル/テキスト〔候補あり・閉じた候補・自由〕/数値〔最小・最大・刻み・単位〕)、ビュー(階層・条件・HOME・起点)、動画ごとのタグ付与とローカルメモ、ビューパックのファイル(UTF-8 JSON)、バックアップファイル。
- 外部から取るもの: チャンネルの公開動画一覧とメタデータ(題名・チャンネル・公開日・長さ・LIVE)、サムネイル画像(セッション中だけ保持、design-intent L26)。
- 出力: 分類結果の閲覧(件数・パンくず・子件数)、ブラウザで動画を開く、ビューパックの書き出し(チャンネル ID・タグ/ビュー定義・付与先の動画 ID のみ)、バックアップ、監査用の適用結果(L1778)。
- 破壊的な流れ: コレクション削除(ローカル分類と、そこにしか属さない動画とメモも消える)、使われていない動画の整理(6,093 本)、タグ・ビューの削除。

**5 分で分かる要約**: YouTube のチャンネルとリンクを「コレクション」として取り込み、手元のカタログに貯めた動画に自分で定義したタグを付け、タグを組み合わせた「ビュー」の階層で分類して見る、ローカルの動画整理アプリ。一括タグ付けと quick action でタグを付け、分類の視点(タグとビュー)はファイルで他人と共有できる。音楽をまとめたビューを起点に「ミュージック」として連続再生する機能が fixture 図面に描き始められている。

## 層 4: 復唱文

このモックを製造すると、次のような振る舞いの製品になる。

1. 画面は「動画」と「タグ」の 2 つで、上部のタブで切り替える。設定は歯車の dialog で開く。About とヘルプは本モックからは未規定。
2. 動画画面は 左=コレクション、中央=結果、右=選択中の動画の詳細 の 3 ペインで、幅が 1050px 未満になると右の詳細が消える。
3. カードはサムネイルの上に 一括選択のチェック・quick action・永続タグ・長さ(または LIVE)だけを重ね、題名とチャンネルはカードに出さず右の詳細に出す。
4. カード本体を押すと詳細の対象が変わり、左上のチェックを押すと一括対象だけが変わる。2 つの選択は別々に見え、同時にも見える。
5. 選択中のカードをもう一度押すとプレイヤーが開く(DOM の属性による)。プレイヤーの中身と閉じ方は本モックからは未規定。
6. 一括対象が 0 本でも「N件選択」と「タグを付ける」は見えたまま残り、0 本のときは押せない。
7. 「結果を全選択」は画面に描かれたカードではなく現在の結果すべてを対象にし、Shift でチェックすると起点から押した位置までを同じ状態にそろえる。全選択の母数が表示件数と一致することは本モックの中で確かめられない(図は 128、見出しは 102)。
8. 範囲選択の起点は、オレンジの枠と「範囲選択の起点」という読み上げで表示される。起点を見せるかの裁定は本モックからは未規定。
9. 一括付与の dialog では、既存タグごとに選択中の動画に「すべて/一部/なし」を出し、タグの種別に応じて値を選ぶか入力し、全員に付けるか外すかを一度に行う。失敗しても dialog と選択は残る。
10. ビューを選ぶと保存済み階層の selector、すべて/未分類の切替、パンくず、子 chip(件数つき)が出て、ビューを解除するとそれらが消え、通常の一覧に戻る。
11. パンくずは祖先を押せるボタンで、現在地は押せない。値で絞った場合は値が現在地になり、その親のノードを押すと値の絞り込みが解除される。
12. 並び替えは 追加日・題名・チャンネル・公開日・長さ の 5 種類で、既定の図面では方向を変えられない。方向を変えられるかは本モックからは未規定(fixture 図面には方向ボタンがある)。
13. 結果には 読込中・同期中・一部完了・空・未分類なし・取消済み・失敗・APIキーなし の 8 つの状態があり、それぞれ説明文と次の操作を出し、失敗を「動画なし」と見せない。
14. 右の詳細のスクロールバーは普段は見えず、ポインタが近づくかスクロール中だけ出る。結果 grid のスクロールバーは常に見える。
15. 詳細には 動画 ID・チャンネル・公開日・追加日・長さ・サムネイルのサイズ・取得元・タグ・ローカルメモ(保存/破棄)が出る。正規 URL・視聴可否・最終確認日時は出ない。
16. 詳細の未選択状態の見た目と、そのとき押せなくなる操作の範囲は、本モックからは未規定(注記は「促す表示+disabled」と決めているが図が無い)。
17. タグ画面では、ビューを選び、パレットのタグを階層へ置き(前に挿入・子にする・ルート末尾)、ノードごとに展開・別名・条件・HOME を設定し、未保存の変更は保存か破棄するまで下部のバーに出る。
18. タグとビューは、他人とビューパックとして共有できる。書き出しは動画一覧やメモや API キーを含まず、取り込みは読取専用の概要 → 競合の解決 → 一括適用 → 結果、の順に進み、途中で止まってもライブラリは変わらない。
19. ローカル分類を持つコレクションは通常の削除が止まり、件数を示したうえで、名前を入力する別の破壊的削除だけが残る。その削除は、そのコレクションにしか属さない動画とメモも消す。
20. 音楽の再生(キュー・シャッフル・ループ・ミュート)は fixture 図面にだけ描かれており、製造範囲に入るか、音量の調整があるかは、本モックからは未規定。
