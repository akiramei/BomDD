### ユーザー操作

- 画像タブの ⋯ →「未裁定の画像…」で、選択中のコレクションの裁定ダイアログを開く。
- 左一覧の行をクリックすると右に詳細が出る(裁定はフッターからだけ)。
- フッター: 受け入れる / 新しい画像として受け入れる(→normal、タグと ID はそのまま)、別画像として扱う(行を置き換えて新しい ID、タグなどは消える)、修復で再リンク…(修復フローへ移る)、削除する(→ゴミ箱)、保留して次へ(状態は変えない)。
- callout の「自動裁定」→ PD-6 →「再リンク」で、対象 N 件を一括で候補の missing へ再リンクする。「キャンセル」なら何も変えない。
- ✕ でいつでも閉じられる。PD-4 では「閉じる」。
- バッジのクリックは本版では何もしない。複数選択による手動の一括裁定は無い。

### データの流れ

- 入力: スキャン(再スキャンの新規、内容変更、再出現)とトラッシュ復元が作る pending 行(由来、candidate_link_id、サイズ・日時・タグ件数、ハッシュ)と、候補の missing 行。
- 表示: 由来チップ・説明カード・比較、自動対象の件数 N(1:1 のハッシュ一致組)、i/N。
- 出力(DB 遷移): T13(→normal)、T14(行の置き換え)、T15(→deleted)、保留(変化なし)、自動裁定は T4(pending 行を消し、missing 行を上書きして normal へ、元の ID とタグは残る)の原子的な一括適用。修復フローへ渡す。

## 層4: 復唱文

1. 再スキャンで見つかった新規ファイル、内容が変わったファイル、再び現れたファイル、トラッシュから物理ファイルのある状態で復元した画像は、「未裁定」になる。画像タブの無絞り込み表示(すべて)では、通常の画像と並んで左上に琥珀の破線バッジ「● 未裁定」付きで表示される。
2. バッジを押しても何も起きない。裁定は ⋯メニュー「未裁定の画像…」から開く専用ダイアログでだけ行う。
3. ⋯メニューのこの行には、選択中のコレクションの未裁定件数が灰色のピルで出る。0 件なら件数は出ないが、行は残る。
4. ダイアログは左に一覧(サムネ・ファイル名・由来チップ)、右に詳細(プレビュー・パス・由来の説明・比較)、下に常に見えるフッターという構成で、タイトルに「(i / N 件)」が出る。
5. 内容変更の画像では「受け入れる」「別画像として扱う」「削除する」「保留して次へ」の 4 つから選ぶ。受け入れるとタグと ID はそのまま残る。
6. 「別画像として扱う」を選ぶと、同じパスで新しい ID の画像に作り直され、元のタグなどは失われる。ただし確認の有無や警告の文言は本モックからは未規定である。
7. 「削除する」はゴミ箱へ送るだけで、物理ファイルは消えず、後で復元できる。復元すると再び未裁定に戻る。
8. 同じ内容のリンク切れ画像がある新規ファイルでは、「修復で再リンク…」で既存の修復画面へ移り、そこで再リンクするとタグが引き継がれる。ダイアログが閉じるか、相手が選ばれた状態で開くかは本モックからは未規定である。
9. 1 件裁定すると、その行は一覧から消えて次の項目が選ばれる。「保留」は何も変えずに次へ進む。並び順と、最後の項目で保留したときの動きは本モックからは未規定である。
10. 移動やリネームで生まれた新規ファイルのうち、同じ同期フォルダ内のリンク切れ画像と 1 対 1 でハッシュが一致するものが 1 件以上あれば、ダイアログ上部に青い帯で「同じ画像だと確認できる未裁定が N 件あります」と「自動裁定(N 件を再リンク)」ボタンが出る。
11. そのとき一覧は、先頭に「自動裁定できる N 件」(各行に青い「自動」チップ)、区切り線の下に「個別に確認 M 件」の 2 段に分かれる。
12. 自動裁定ボタンを押すと確認ダイアログで対象 N 件(サムネ・名前・再リンク先)を一覧できる。「再リンク」を押すと、全件が一度に元の画像へ付け替えられる(元の ID とタグは残り、リンク切れは解消する)。「キャンセル」なら何も変わらない。
13. 内容変更・再出現・復元の画像と、リンク切れの相手がいない新規・相手の決まらない新規は、自動裁定に入らず、1 件ずつ裁定する。
14. 確定時に 1 組でも条件を満たさなくなっていれば何も適用されない(全件取り消し)。そのときの画面の表示と、実行中の表示は本モックからは未規定である。
15. 自動裁定を後で「取り消す」専用の操作があるかどうかは本モックからは未規定である。確認文は取り消せると述べているが、それに当たる操作は描かれていない。
16. 未裁定が 0 件になると(自動裁定で片付いた場合も)、「未裁定の画像はありません」と「閉じる」だけの空の画面になる。
17. ✕ はいつでも押せる。裁定した分は確定したまま残り、残りは未裁定のまま次回に持ち越される。
18. キーボード操作、ダイアログの大きさの変更、英語表示、閉じた後に画像タブを読み直すかどうかは、本モックからは未規定である。
