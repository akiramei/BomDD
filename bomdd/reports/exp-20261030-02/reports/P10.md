# UI モック受入検査報告書 — ViewTube V1(モックパッケージ P10)

## 0. 入力と読み方

入力(このフォルダ内のみ):

- 設計者注記: `notes/design-intent.md`、`notes/unresolved-questions.md`、`notes/videos-cad.md`
- モック: `mock/viewtube-v1.html`(1 ファイル。行番号はこのファイルの行)
- 要求・仕様: `ruled/10-requirements.yaml`、`ruled/20-spec.md`

モック内には描画の層が 4 つある。以下の所見では、どの層の話かを `[静的]` `[既定]` `[fx]` `[状態]` で示す。

| 記号 | 層 | 根拠 |
|---|---|---|
| `[静的]` | HTML に直接書かれたマークアップ | 1203–1939 行 |
| `[既定]` | 起動時に script が作り直す既定状態(出演者ノード)。静的マークアップは「スクリプトなし時の代替」と宣言されている | 2738–2740 行 `renderSavedNode()` |
| `[fx]` | `?base=fixture` のとき script が画面全体を作り直す「捕捉用 fixture 上の製品の見た目」 | 3019–3730 行 |
| `[状態]` | URL パラメータや CAD 状態切替で到達する状態(batch=range、music=open、assignvalue=…、fixturestate=… など) | 2741–3018 行 |

描画専用の仕掛け(製品の部品ではないとモック自身が書いているもの): `.cad-switcher`(1928–1939)、`.pointer-over`(446、ホバーの代用)、`.menu-open`/`.context-menu.open`(右クリックの代用)、`.sync-toast.open`(1301–1310)。これらは製品の欠陥として扱わない。

静的マークアップのパンくずが「所属」を現在位置にしている件(1398 行)は、既定状態で `renderSavedNode()` が「人物カタログ › 出演者」に作り直すため矛盾として扱わない(この型は UQ-UI-019 で閉じられている)。

本書は判定ではなく、候補と質問を示すものである。「正しいのはどちらか」は書かない。

## 層4: 復唱文(このモックを製造すると、こう振る舞う製品になる)

1. 起動すると、上部に「動画」「タグ」の切替と設定の歯車が出て、既定では動画画面が開く。
2. 動画画面の左には「すべての動画」「ミュージック」、その下に手動コレクションとチャンネルコレクションが並び、チャンネルの行には最後の確認の種類(新着確認/全件確認)と時期、または「取り込み対象外」が文字で出る。
3. 左上の ⟳ を押すと、取り込み対象のすべてのチャンネルの新着を順に取り込み、結果はレールに重なる通知で出て、失敗がなければ数秒で消える。失敗を含む通知の閉じ方は、本モックからは未規定。
4. 全件の再確認と、取り込みの除外/含めるは、コレクション行の右クリックメニューからだけ行える。
5. ビューを選ぶと、保存済み階層のメニュー、すべて/未分類、パンくず、子の件数 chip が出る。× でビューを解除すると、これらは消えて通常の結果に戻る。
6. 動画カードは 270px 以上の幅で並び、サムネイルと長さ(またはLIVE)と永続タグを見せる。題名とチャンネル名をカードに出すかどうかは、本モックからは未規定(注記どうしが食い違う)。
7. カード本体を押すと、その動画が右の詳細に出る。カード左上のチェックボックスは、一括処理の対象にだけ作用する。
8. チェックボックスを Shift を押しながら押すと、前に押したところからの範囲をまとめて揃える。起点が画面上でどう見えるかは、本モックからは未規定。
9. 「結果を全選択」は、画面に描かれたカードだけでなく、今の結果の全件を対象にする。ただしその全件の数が見出しの件数と同じかどうかは、本モックからは未規定(102 と 128 が併存)。
10. 一括選択が 0 件でも「0件選択」と「タグを付ける」は見えたままで、タグを付けるは押せない。
11. 「タグを付ける」は既存タグを選ぶモーダルを開き、タグの型に応じて値を受け(候補が 20 個以下なら選択肢、それより多ければ入力)、受け付けない値のときは「付ける」を押せなくして理由を出す。
12. カード上のクイックアクション(お気に入り・あとで見る・要確認)は、ポインタが乗ったときだけ見え、付いているものは常に見える。押したとき詳細の選択が動くかどうかは、本モックの振る舞いと要求が逆で、未確定。
13. 詳細には動画ID・チャンネル・公開日・追加日・長さ・サムネイルのサイズ・取得元・タグ・ローカルメモ(保存/破棄)が出る。canonical URL・availability・最終確認日時は出ない。
14. 「動画を開く」は既定のブラウザで動画を開く。詳細のサムネイルを押したときにアプリ内でプレビューするかどうか、何が見えるかは、既定の描画からは未規定(fixture の描画にだけ「プレイヤーを開く」がある)。
15. ミュージックは、起点のビューの条件で中身が決まる枠で、起点がないときは空のまま「起点を決める」を求める。そこでだけ、選んだ動画(未選択なら全件)を順に、またはシャッフルで再生でき、再生は他の画面へ移っても続き、他の画面からは一時停止と停止だけができる。
16. タグ画面は、左がビュー管理(起点の設定を含む)、中央が階層の編集(保存/破棄)、右がタグパレットの 3 ペインで、タグ画面からは動画の結果へ移る操作はない。
17. スコープ付きのデータを持つコレクションは通常の削除が止められ、専用の削除では、その件数と、消える動画の数を示してから消す。スコープ付きデータのないコレクションを削除するときの見た目は、本モックからは未規定。
18. ビューやタグを削除するときは、件数を示す確認を通る。削除が拒否される場合にどう見えるかは、本モックからは未規定。
19. 設定では、表示言語、API キーの設定・置き換え・削除、バックアップ/復元、使われていない動画の整理、ビューパックの取り込み/書き出し、ミュージックを一覧に出すかどうかを扱う。About・ヘルプ・バージョン表示は、本モックからは未規定。
20. アーカイブした動画の一覧と、元に戻す操作は、本モックからは未規定。
