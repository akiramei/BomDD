### 2-2. ユーザー操作の一覧(モックが示すもの)

- **全体**: 動画とタグの画面切替、設定を開く。
- **左ペイン(Videos)**: すべての動画、手動コレクション、チャンネルコレクションの選択。「＋ リンク」(行き先なし)、「＋ チャンネル」(モーダルを開く)。
- **中央ペイン(Videos)**: ビューの選択、すべて/未分類の切替、検索の入力、並び替え(項目と方向の組で 5 択)、grid/list の切替、子のチップで下の階層へ移る(行き先なし)。カード本体のクリックで詳細を選ぶ。カードのトグルで一括選択に足す・外す。「タグを付ける」でモーダルを開く。状態カードの主ボタン(credential のときだけ設定を開く)。
- **右ペイン(Videos)**: 「動画を開く」、「⋯」(アーカイブ)、メモの編集・破棄・保存。
- **付与モーダル**: 既存タグの検索、タグを 1 つ選ぶ、値を選ぶ(select)、「3本から外す」「3本に付ける」「キャンセル」「×」。
- **Tags**: ビューの検索・選択・新規、「ビュー設定」、階層の行のドラッグ・展開と折りたたみ・「結果」(Videos へ移る)・「•••」、警告の「設定を確認」、保存・破棄。パレットの検索・「＋ タグ」・カードで配置開始・「•••」編集。
- **チャンネル追加**: 参照の入力、「戻る」「追加して同期」。
- **設定**: 表示言語、API キーの置換(または設定)と削除、完了。

### 2-3. データの流れ

- **入力**: YouTube のリンク(行き先の画面は未描画)、チャンネルの参照(@handle/URL/ID)、API キー(入力欄は未描画)、検索語、メモ本文、タグ値(定義値から選ぶ)、階層の配置。
- **出力・表示**: コレクションごとの件数と同期状態(文言+点の色)。動画カード(サムネイル、または placeholder と時間/LIVE と永続化済みタグのチップ)。詳細(ID・チャンネル・公開日・長さ・取得元・確認日時・タグ・メモ)。分類の経路(パンくず・子の件数・結果件数・モード)。タグの集計状態(すべて/一部/なし)。タグの使用数と定義値。分類設定の警告。OS の既定ブラウザで canonical URL を開く。
- **永続化の対象**(モックの文言から): メモ、タグの割当、階層。サムネイル画像は保存しない(DI:20)。

**5 分で読む要約**: ViewTube は、YouTube 動画へのリンクを、取得元(手動・チャンネル)ごとにローカルへ集める Windows アプリである。タグ(シンプル・テキスト・数値)と、ビューごとのタグ階層で、フォルダのように分類して閲覧する。Videos 画面では、コレクションとビューの階層で絞り込み、サムネイルのカードを見て、1 本を右の詳細で確認し、チェックで複数本を選んで既存タグを一括で付けたり外したりする。Tags 画面では、ビューを管理し、パレットのタグをドラッグして階層を組み、明示的に保存・破棄する。動画の再生は外部ブラウザで行う。チャンネルの同期には、ユーザーが用意する API キーが要る。

## 層4: 復唱文

このモックを製造すると、次のような振る舞いの製品になる。

1. 上部に「動画」「タグ」の 2 つの画面切替と設定ボタンがあり、取り込み元にあった画像・ファイル系の画面は無い。
2. 動画画面の左に「すべての動画」と、手動・チャンネルに分けたコレクションの一覧と、件数が並び、チャンネルには同期状態が文言と点で出る。
3. 動画画面の中央の上で、ビューを選び、すべて/未分類を切り替え、題名・チャンネル・ID・メモで検索し、項目と方向が組になった 5 択で並び替え、grid/list を切り替える。ただし list の見た目と、ビューを選ばない状態は、本モックからは未規定である。
4. グリッドのカードは、160px のサムネイル(取得できたら実画像、できなければ決定的な placeholder)、時間または LIVE、永続化済みタグのチップだけを示し、題名とチャンネルはカードに出さない。
5. カード本体を押すと右の詳細に 1 本だけ表示され、カード左上のトグルは、詳細とは無関係に一括処理の対象へ足したり外したりする。
6. パンくずは現在の経路を示すだけで、上へ戻る操作は本モックからは未規定である。子のチップを押すと下の階層へ移り、チップの件数はすべて/未分類のモードに従う。
7. 未分類に切り替えると、結果と子の件数は未分類の式で変わる。そのとき一括選択・詳細のタグ・カードのタグがどうなるかは、本モックからは未規定である(モックでは変わらない)。
8. 一括選択が 0 件のとき「タグを付ける」は押せない。1 件以上のときは、既存タグを選ぶモーダルが開き、タグごとに選択中の本数に対して「すべて/一部/なし」が文言で示される。
9. モーダルでは 1 つのタグを選び、シンプルタグは値なし、テキストと数値は選択肢から値を選び、「N本に付ける」「N本から外す」で全部に一度に反映する。失敗したら選択と画面を保持する。自由入力ができるか、処理中や失敗時の見た目は、本モックからは未規定である。
10. モーダルからタグ定義を新しく作ることはできない。
11. 詳細ペインには、サムネイル、題名、「動画を開く」(外部ブラウザ)、アーカイブ、動画 ID・チャンネル・公開日・長さ・取得元・確認日時、タグ(表示だけ)、ローカルメモと破棄・保存がある。canonical URL と availability の表示、メモの dirty の表示は、本モックからは未規定である。
12. アーカイブした動画をどこで見て、どう復元するかは、本モックからは未規定である。
13. 読込中・同期中・一部完了・空・未分類なし・取消済み・失敗・API キー未設定は、それぞれ専用の説明と 1 つの主ボタンを持つ状態カードとして、中央の結果の代わりに表示される。
14. タグ画面は、左がビュー管理、中央が階層の編集、右がタグパレットの 3 ペインである。パレットのタグをドラッグで階層へ配置し、行をドラッグで並べ替え、親の行だけが展開・折りたたみのボタンを持つ。
15. 階層を変更すると「未保存の変更」が出て、保存バーの保存・破棄で確定する。未保存のときに他の画面への移動を止める見せ方は、本モックからは未規定である(モックでは止まらない)。
16. 分類の評価は、正常なら何も表示しない。利用者が直せる問題(例: 数値の範囲が広すぎる)があるときだけ、中央に警告と「設定を確認」を出し、保存済みの階層は変えない。
17. 各階層の行の「結果」を押すと、動画画面へ移ってその分類の結果を開く。どのビュー・経路・モードが設定されるかは、本モックからは未規定である。
18. チャンネルの追加は、URL・@handle・ID を入れて、題名・ID・公開動画数の preview を確認し、「追加して同期」で確定する。解決ボタン、0 件・複数件・エラーの表示、同じチャンネルの重複は、本モックからは未規定である。
19. 設定では、表示言語の日本語/英語、API キーの有無(値は表示しない)、置き換えと削除ができる。キーを入力する欄、バックアップと復元は、本モックからは未規定である。
20. 幅が 1050px 未満では右ペイン(詳細・パレット)が消える。そこへ到達する手段は、本モックからは未規定である。

## 検査サマリ

- 矛盾候補: **32 件**(C-01〜C-32)。このほか、要求・仕様が求めるのにモックに無いもの **14 件**(M-01〜M-14)、モックにあるのに要求・仕様が述べないもの **4 件**(X-01〜X-04)。合わせて 50 件。
- 質問: **20 問**(high 10、medium 9、low 1)
- 製造着手前に裁定を推奨する上位項目:
  1. **同じ fixture の中の整合(C-03・C-04・C-05・C-06)**: 未分類で再投影しないタグ、パレットとモーダルでタグの在庫が違う、色の不一致、評価の使用数 0 本。DI:16 と DI:25 の「単一の fixture」「永続化済みの投影」を、モック自身が満たしていない。UQ-UI-007 の golden の対象そのものである。
  2. **選択のライフサイクル(C-02・C-14、質問 1・2)**: モードを切り替えたときの一括選択の積集合、キーボードで詳細と一括の分離が崩れる経路、詳細選択の消滅規則。
  3. **付与の値入力の意味論(C-07、質問 3・4)**: select だけでは suggest ドメインと数値の範囲を満たせない。詳細ペインから 1 本に付ける経路の有無。

  5. **カードに題名を出さない方針と REQ-042(C-16・C-17)**: 注記と要求の文が衝突している。非表示の固定タグ文字列が残っている。
  6. **状態カードが結果を置き換えること(C-20、質問 9)**: partial・credential のときに、ローカルの結果を隠してよいか。
  7. **基準点(質問 5・10)**: 「結果」から移った先のビュー・経路・モード、grid/list を切り替えたときの基準点。
