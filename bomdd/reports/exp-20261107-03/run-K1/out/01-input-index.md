## 2. 対象範囲

含める:

- インスペクター下部「出力フレームレート (fps)」のプリセット 5 個(ソース / 24 / 30 / 60 / 120)と、その選択表示
- アップサンプル注記(ソースより高い fps を選んだときの注記)
- 「ソース」ボタンのツールチップ(元動画の fps)
- クリップ情報欄の「フレームレート」(元動画の fps)
- 書き出しダイアログのサマリ「フレームレート」
- 出力 fps が高速・無劣化(コピー)の可否に与える影響
- 保存状態の表示(未保存の変更 / 保存済み)への影響
- Undo / Redo との関係(履歴に入るか)
- 動画を開いたときの初期値・別の動画を開いたときのリセット
- 元動画の fps の取得(ffprobe の値・VFR 判定)と、書き出し時の ffmpeg 引数への反映(コードを読んだ範囲)
- 元動画の fps に依存する編集操作(1 フレーム送り・フレームスナップ・タイムコード)が、出力 fps に**依存しない**こと

含めない(今回は読まない・決めない):

- 書き出された動画ファイルの実際のフレームレート・フレーム数(アプリ実行・ffmpeg 実行が禁止のため観測不能)
- 速度変更・トリム・解像度そのものの仕様(出力 fps と接する点だけ扱う)
- 言語切替そのもの

## 4. 例(examples.json)の前提

- 依頼の共通開始状態: 「30 fps の固定フレームレートの動画を開いた直後。ほかには何もしていない」。
- **画面の言語は日本語と仮定した**(DESIGN_CHOICE)。原製品は設定ファイルの言語か、無ければ OS の UI 言語が ja なら日本語・それ以外は英語(Program.cs:24-33)。
  開始状態に言語の指定がないため、例の要素名には英語表記を括弧で併記した。文字を比較する `shows` は「未保存の変更」「保存済み」だけで、
  英語 UI なら "Unsaved changes" / "Saved"(Strings.resx:70-71)に読み替える。数値の表示("30 fps" 等)は言語に依存しない(README.md:149)。
- 開いた動画のコーデック・長さ・音声の有無は開始状態に無い。これらに依存する表示(コピーのトグルが開いた直後に見えるか、長さの表示)は例で主張していない。
