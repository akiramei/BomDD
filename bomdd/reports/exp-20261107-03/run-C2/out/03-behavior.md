# 出力フレームレート — 振る舞い(操作ごとの前後と画面)

前提: 日本語 UI。ソース fps を `S` と書く。具体例は `S = 30`(固定フレームレート)。
画面の場所:
- **プリセット列** = インスペクター下部「出力解像度」セクションの中、「出力フレームレート (fps)」見出しの下の
  「ソース / 24 / 30 / 60 / 120」ボタン。インスペクターは動画があるときだけ出る。
- **注記** = プリセット列の下の「ソースより高いfpsはフレーム複製になります（画質は向上しません）。」
- **状態表示** = タイトルバーのファイル名の右「保存済み」/「未保存の変更」。
- **ダイアログ** = ツールバー右上「書き出し」で開く書き出しダイアログ。サマリに「出力解像度」「フレームレート」「出力時間」。

## B1 動画を開く(「開く」またはドラッグ&ドロップ)

| | 後 |
|---|---|
| 状態 | outputFps = S、edited = 偽、履歴は空、fastCopy = 偽 |
| プリセット列 | 「ソース」点灯。数字ボタンは outputFpsText と同じ文字のものだけ点灯(S = 30 なら「30」も点灯、S = 25 なら数字はどれも消灯) |
| 注記 | 隠れる |
| 状態表示 | 保存済み |
| 元に戻す/やり直す | 押せない |
| 「ソース」のツールチップ | 元動画と同じ（30 fps） |

前に別の動画で出力 fps を変えていても、新しい動画の S に戻る。

## B2 「ソース」を押す

| | 前 → 後 |
|---|---|
| outputFps | 任意 → S |
| プリセット列 | 「ソース」点灯。S と同じ文字の数字ボタンも点灯 |
| 注記 | 隠れる |
| 状態表示 | → 未保存の変更(すでに S でも) |
| 元に戻す | 変化なし(この操作は積まれない) |
| コピーの選択肢(ダイアログ) | 他の条件を満たせば再び表示。以前のチェック状態(fastCopy)はそのまま残る |

## B3 「24」「30」「60」「120」を押す(値 n)

| | 前 → 後 |
|---|---|
| outputFps | 任意 → n |
| プリセット列 | 押した n が点灯。\|n − S\| < 0.05 なら「ソース」も点灯、そうでなければ消灯 |
| 注記 | n > S + 0.05 なら表示、それ以外は隠れる(S = 30: 24・30 → 隠れる、60・120 → 表示) |
| 状態表示 | → 未保存の変更(値が同じでも) |
| 元に戻す | 変化なし |
| コピーの選択肢(ダイアログ) | n が S と 0.05 を超えて違えば隠れる(書き出しは再エンコード) |

## B4 元に戻す / やり直す(ツールバーのボタン、Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y)

- 区間編集だけが戻る/進む。outputFps・プリセット列・注記は変わらない。
- 出力 fps しか変えていないとき、元に戻すは押せない(押しても何も起きない)。
- 状態表示は「未保存の変更」のまま(元に戻しても「保存済み」には戻らない)。

## B5 書き出しダイアログを開く

| 表示 | 値 |
|---|---|
| サマリ「フレームレート」 | outputFpsText + " fps"(開いた直後の 30 fps 動画なら「30 fps」、60 を選んだ後なら「60 fps」) |
| 「高速・無劣化（コピー）」 | canStreamCopy のときだけ表示(02 §4)。出力 fps を変えた・区間速度を変えた場合は必ず隠れる |
| 出力時間 | 出力 fps では変わらない |

ダイアログは画面全体を覆うので、開いたまま出力 fps は変えられない(外側を押すと閉じる)。

## B6 書き出す(ダイアログの「書き出す」→ 保存先を選ぶ)

- 進捗に「フレーム N」(出力済みフレーム数)・速度・残り時間。
- 成功: ダイアログが閉じ、状態表示は「保存済み」。outputFps は残る。
- 失敗・中止: ダイアログに理由。outputFps・状態表示は変わらない。
- 出力されるファイル: 02 §4 のとおり(再エンコードでは outputFps の CFR、コピーでは元のタイミングのまま)。

## B7 コマ送り・タイムコード(出力 fps と無関係であることの確認)

- 「1フレーム進む」(→ / .)・「1フレーム戻る」(← / ,): 1/S 秒ずつ動く。outputFps = 60 でも 1/30 秒。
- トランスポートの再生位置タイムコード: M:SS:FF の FF は S で数える。開いた直後 0:00:00、1 フレーム進むと 0:00:01。

## B8 別の言語で見たとき(英語 UI)

| 日本語 | English |
|---|---|
| 出力フレームレート (fps) | Output frame rate (fps) |
| ソース | Source |
| 元動画と同じ（30 fps） | Same as source (30 fps) |
| ソースより高いfpsはフレーム複製になります（画質は向上しません）。 | An fps higher than the source duplicates frames (quality does not improve). |
| フレームレート | Frame rate |
| 未保存の変更 / 保存済み | Unsaved changes / Saved |
| 高速・無劣化（コピー） | Fast, lossless (copy) |

## examples.json との対応

| 例 | 振る舞い |
|---|---|
| EX-01 | B1 |
| EX-02, EX-03, EX-05 | B3 |
| EX-04 | B3 → B2 |
| EX-06, EX-07, EX-08 | B5(+ B3/B2) |
| EX-09, EX-10 | B4 |
| EX-11 | B7 |
| EX-12 | B5(区間速度によるコピー不可) |

examples.json では、開いた直後のコピーの選択肢の表示は書いていない(動画のコーデック・音声で決まり、
「30 fps の固定フレームレートの動画」という前提だけでは決まらないため)。
