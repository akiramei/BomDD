### 1.1 「R-050 の所見なし」の定義(本 ECO の中心)

- **指す状態**: error の R-050 が無く、抑止(suppress)された R-050 も無い。抑止つきの通過は出力に残る別の状態で、所見なしとして引用しない。
- **支持すること**: 最新エントリが、対象の全 CP について合格を申告し、合格以外の申告行を持たない。
- **支持しないこと**: ①証拠ファイルの中身が合格を示すこと(result は記録者の申告値)②証拠が現在の成果物の個体に対するものであること ③最新より前のエントリの内容
  ④本ゲートが製品の判定経路で実行されていること。

### 1.2 設計上の選択と理由

| 選択 | 採った案 | 退けた案と理由 |
|---|---|---|
| 合格の定義 | 文字列 pass の完全一致のみ | 語彙外の値(実在 3 種)を合格に読む — 意味を推測することになり、測定不能を合格にする |
| (b) の対象 | 最新エントリの全行 | 受入対象の CP の行だけ — 実在標本の 1 件(受入対象外の CP の不合格行)が見えないまま残る |
| (c) の重さ | error | warn — 受入ゲートで測定不能を通すと、所見なしが「測れなかった」を含んでしまう |
| (c)(d) を出すゲート | 実行ゲートが acceptance のときだけ | 全ゲートで出す — 製造前は製造記録が無いのが正常で、既存の検体の大半が所見ありへ変わる(実測: (a) の所見は現行でも全ゲートで出力に載る) |
| 規則の分け方 | R-050 を改める | 別の規則を新設 — 「R-050 の所見なし」の証拠能力は戻らない |

**採らない**: 「最新」の定義の変更(リスト末尾)/ リポ単位の判定 / retired の製造単位の除外 / 文書方言の製造記録に対する被覆検査 / 合否値の語彙の拡張 /
テンプレート・契約文書(50-as-built・traceability-rules・plm-ready-contract)の改訂 / 受入ゲートを製品の判定経路へ結線すること / 証拠ファイルの中身の検査。
前 3 つは所見を過剰に出す側(偽陽性)で、所見なしの意味を弱めない — OBS-20260929-08 に記帳。
